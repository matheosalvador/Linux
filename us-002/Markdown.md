# **Structure de base du tableau :**

>Les tableaux Markdown sont créés en utilisant des barres verticales (|) pour séparer les colonnes et des traits d'union (-) pour définir la ligne d'en-tête. Voici la structure de base :

### **Ligne d'en-tête :** 
>La première ligne contient les noms des colonnes.

### **Ligne de séparation :** 
>La deuxième ligne utilise des traits d'union pour séparer l'en-tête des données.

### **Lignes de données :** 
>Les lignes sous la ligne de séparation contiennent les données réelles.

>**La syntaxe des tableaux Markdown est assez simple. Un tableau de base est composé d'une rangée d'en-têtes, suivie d'une ligne de séparation, puis des lignes de données :**

| Name  | Age |  City    |
|-------|-----|-------|
| Alice | 25  | New York |
| Bob   | 30  | London   |
